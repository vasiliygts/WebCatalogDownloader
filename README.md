# WebCatalog Downloader

Графічна утиліта для вибіркового завантаження файлів з відкритих веб-каталогів
(Apache / nginx autoindex): дерево папок з трипозиційними галочками, вибір за
маскою, багатопотокове завантаження з докачуванням.

Тільки стандартна бібліотека Python 3.8+ (`tkinter`). `certifi` — опційно,
підхоплюється автоматично, якщо встановлений.

## Запуск

```
python webcat_downloader.py
```

## Можливості

- Лінивий обхід дерева каталогу; кнопка **«Сканувати все»** для повного рекурсивного обходу.
- Трипозиційні галочки (☐ / ☑ / ◪) з поширенням стану на вкладені елементи.
- Множинне виділення рядків: клац по галочці всередині виділення відмічає всю групу.
- Вибір за маскою (`*.pdf *.epub` тощо), інвертування, «вибрати/зняти все».
- Розмір папок — сума розмірів прочитаних файлів (`≥` поки гілку не обійдено повністю).
- Багатопотокове завантаження (1–8 потоків) зі збереженням структури підпапок і докачуванням `.part`.
- Експорт списку вибраних URL для `wget` / `aria2c`.
- Basic-auth.
- Керування перевіркою TLS: власний CA-bundle, режим без перевірки, кнопка **«Тест з'єднання»** з діагностикою ланцюжка сертифікатів.

## tlscheck.py

Окремий консольний скрипт для діагностики TLS, якщо GUI не може встановити з'єднання:

```
python tlscheck.py hostname [port]
```

Показує повний ланцюжок сертифікатів з термінами дії та перевіряє його системним сховищем і через `certifi`.
